Backups and export

A backup is made every night at 03:30 and when the app starts after a day without one; the newest 14 are kept in data/backups. To restore one, run these in the project folder; the current database is kept next to it as jobhunt.db.before-restore-…:

docker compose stop
docker compose run --rm jobhunt /app/.venv/bin/python -m jobhunt.backup restore data/backups/<file>
docker compose start
